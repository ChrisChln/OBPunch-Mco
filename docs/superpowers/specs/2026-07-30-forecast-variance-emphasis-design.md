# 预测差异强调与差异件数设计

## 目标

让历史流入表更容易识别预测偏差，并新增可直接阅读的差异件数。

## 计算规则

- 实际差异继续使用 `(当日总流入 - 截止12点预测) / 截止12点预测`。
- 颜色判断只使用实际差异的绝对值，不区分正负方向。
- `|实际差异| > 8%`：实际差异与差异件数均使用加粗红色。
- `|实际差异| < 3%`：实际差异与差异件数均使用加粗绿色。
- `3% <= |实际差异| <= 8%`：保持普通文字样式。
- 差异件数使用 `当日总流入 - 截止12点预测`，保留正负号并使用千位分隔符。
- 缺少预测、当日总流入或完整日数据时，两项均显示 `-`，不应用强调色。

## 界面范围

- 页面中的“历史流入”冻结列新增“差异件数”，放在“实际差异”之后。
- 弹窗中的历史流入周表同步新增“差异件数”，位置与样式一致。
- 调整冻结表宽度，保持列对齐，不改变右侧小时表。

## 代码结构

- 将差异件数计算和阈值样式选择提取为小型纯函数，页面与弹窗共用。
- 不修改预测算法、数据查询或数据库结构。

## 测试

- 覆盖正负 `2%` 均为绿色加粗。
- 覆盖 `3%`、`8%` 及区间内值保持普通样式。
